                                                                                
 Usage: melee-agent debug dump restore-object-report [OPTIONS] C_FILE           
                                                                                
 Safely restore one source's object and build report.                           
                                                                                
 This is the managed cleanup path used by match-iter-first --auto-verify.       
 It previews the ninja plan first, refuses unexpectedly large rebuilds by       
 default, and runs the restore in an owned process group with a timeout.        
                                                                                
╭─ Arguments ──────────────────────────────────────────────────────────────────╮
│ *    c_file      TEXT  Path to the .c file whose object/report state should  │
│                        be restored.                                          │
│                        [required]                                            │
╰──────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────╮
│ --timeout          FLOAT    Restore timeout in seconds. Defaults to          │
│                             MWCC_DEBUG_RESTORE_TIMEOUT, then                 │
│                             MWCC_DEBUG_HANG_TIMEOUT, then 180.               │
│ --max-steps        INTEGER  Maximum ninja dry-run steps allowed before       │
│                             refusing to launch restore. Defaults to          │
│                             MWCC_DEBUG_RESTORE_MAX_STEPS (64).               │
│ --force                     Run even when the dry-run plan exceeds           │
│                             --max-steps.                                     │
│ --help                      Show this message and exit.                      │
╰──────────────────────────────────────────────────────────────────────────────╯
