
 Usage: melee-agent debug retro [OPTIONS] COMMAND [ARGS]...

 Retail-binary MWCC introspection via retrowin32 + gdb (GC/1.2.5n front-end IRO
 and backend/regalloc traces, plus GC/1.1 backend dumps).
